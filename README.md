# PollyPM Website

Marketing and documentation site for `pollypm.com`.

## Stack

- Astro for a static-first marketing and docs build
- Plain Astro components and CSS for a lightweight deployable site

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Current Pages

- `/` marketing landing page
- `/docs/getting-started` documentation entry point
